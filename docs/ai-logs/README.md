Como el grupo usa programación agéntica, todo cambio entra por PR a `main` protegido con 2
aprobaciones (enunciado E2, RDOC02), y el log va en el mismo PR que el trabajo. Una fila con
"—" significa que esa persona no tiene log en ese repo; si no usó IA, igual debe existir su
archivo con la declaración de no-uso.

Lo que se haga con IA en el repo `contratos` también se registra acá.
